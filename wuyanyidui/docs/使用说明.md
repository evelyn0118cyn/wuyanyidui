# 财务舞弊111 · 使用说明

> 本系统是**舞弊审计调查岗位**的 AI 助理。你负责判断与决定，它负责提示与整理。
> 任何风险等级、评分、线索优先级都是**参考值**，必须由你复核后才能使用。

---

## 一、第一次打开

| 你需要什么 | 怎么做 |
|---|---|
| 什么都不装，先看看 | 双击 `web/index.html` |
| 用大模型、连数据库 | 双击 `start.bat`（需 Node.js 18+） |

页面顶部四个状态一目了然：

```
[数据源：预置演示数据（合成）（561 笔流水）]  [大模型已连接 · deepseek-flash · 记忆开]  [⚙ 大模型API设置]
```

- 第二个状态显示 **「本地模式」** 时，表示未启动本地服务或未配置 Key —— **不影响任何离线分析功能**，只影响 AI 生成类文字。

## 二、典型工作流程

系统按真实的舞弊调查顺序组织，**上游结果自动流入下游**：

```
数据接入 → 风险信号识别 → 线索台账 → 关联方核查 → 全科目汇总 → 评分评估 → 报告草稿
   F4          F1            F2          F3           F4          F5         F6
```

> 跨模块联动：任一上游模块重算，下游模块会在左侧导航显示 `!` 提示"需重新生成"，避免用过期的数据下结论。

### 最快上手：工作台

1. 点 **「加载预置演示数据」**
2. 点 **「▶ 一键完成全流程分析」**
3. 在进度区看到每个模块的关键结果，再逐页细看

### 换成自己的数据

进入 **数据汇总** 页，三种方式任选：

- **预置演示数据** —— 先熟悉功能
- **上传 Excel / CSV** —— 点击或拖拽。表名/列名含"银行流水、凭证分录、科目、客户、供应商、员工"等中文即可自动识别；只上传流水表时，其余表自动用演示数据补齐（页面会明确提示）
- **连接数据库** —— 需 `start.bat` 已启动、`.env` 配好 MySQL、本机装 mysql 客户端

上传后可点 **「汇总并生成数据质量报告」** 查看全科目汇总、借贷平衡校验与数据质量问题。

## 三、各页面怎么用

### 风险信号识别（F1）

- 点 **「开始筛查」**。结果分为：统计卡 → 校验提示 → 统计基线 → 图表 → 信号清单
- **统计基线**关键：把均值、σ、Q1/Q3、IQR 上界、MAD 上界都摊开给你看，便于复核"为什么这笔被标出来"
- 信号清单支持：搜索、按风险等级/规则/舞弊类型/个人或单位筛选、按列排序、**点行展开"命中依据"**、按列导出 CSV
- 展开后可点 **「🤖 让 AI 解读这笔信号」**（需大模型；否则本地模式生成）
- 想改阈值：点 **「阈值设置」**，保存后写入记忆并在下次分析回显

### 线索台账（F2）

- 点 **「生成线索台账」**。可选"综合权重优先 / 金额优先"排序
- 每条线索展开后包含：
  - **排序理由**（金额占 40%、规则种类 30%、关联方 20%、链路完整性 10% —— 每项都列出实际数值）
  - **资金链路追踪**（完整 / 断点 / 疑似回流）+ 链路示意图
  - **资金—业务交叉核对**（有资金无业务 / 有业务无资金 / 金额不匹配）
  - **四流合一检查**（合同流/发票流/资金流/货物流逐项缺口）
  - **建议核查方向**（只是调查方向建议，不是处置建议）

> 优先级只用于安排**先查哪条**，不代表线索价值，更不能理解为舞弊可能性。

### 关联方核查（F3）

- 点 **「执行关联方核查」**。四类命中分别计数展示
- 清单展开可见：命中依据、股权穿透链条、需人工核实的要点
- 点 **「工商信息」** 可查看/粘贴 JSON 替换股权数据，或通过本地代理采集公开工商信息
- 网络图：红点 = 命中关联核查的对手方；旁边柱状图看集中度

> 关联关系是否成立，必须以工商档案与访谈为准。系统只做初筛。

### 数据汇总（F4）

- 全科目汇总表：勾选"仅末级/仅汇总级/有发生额"筛选，支持按列导出
- 借贷平衡：显示借方/贷方合计、差额、**不平衡凭证明细**
- 数据质量报告：空值率、重复记录、借贷不平、未勾对流水、跨期记录、主数据缺外键 —— 每项都给出**影响提示**

> 如果借贷不平或数据质量问题较多，**先整改数据再分析**，否则所有指标都会失真。

### 评分评估（F5）

- 点 **「生成评估」**。顶部结论条给出综合参考分值与区间（**必定附带"需人工复核后定级"**）
- 雷达图看七类舞弊的相对强弱；明细表可展开每个维度的**计分公式与原始指标**
- 想改权重：**「查看/调整权重」**，改完自动归一化重算
- 点 **「🤖 解释这个分数」** 可让模型说明高分/低分原因与局限性

> 分数用于**分配你的复核注意力**，不是舞弊概率。

### 报告草稿（F6）

- 填好标题/被调查单位/复核人（记忆保存），点 **「生成报告初稿」**
- 报告为**十节结构**，结论段**留空**由你填写，末尾有签署栏
- 导出：**HTML（可 Ctrl+P 打印为 PDF）** / **Markdown** / **附表 CSV**，或页内预览
- 点 **「🤖 AI 润色叙述段」** 可让模型补一段叙述文字（数据仍以表格为准）
- 顶部强制声明**带锁标记，不可删除、不可编辑**

### 测试示例

- **「▶ 运行全部样例」**：自动加载演示数据、跑完整流水线、校验 10 个用例，输出通过率与判定细节
- 每个用例都展示"场景 → 期望 → 判定细节"，可直接用于验收

### 设置

- 记忆开关、当前记忆内容一览、关注舞弊类型勾选
- 恢复默认 / 清空记忆 / 修改阈值
- 大模型与小代理连接状态、安全合规说明

## 四、常见问题

**Q：顶部显示"本地模式（代理未启动）"，要紧吗？**
A：不影响筛查、汇总、评分、报告等所有核心功能。只有"AI 解读/润色/问答"会改用内置规则生成（界面会标注）。想用真模型就双击 `start.bat`。

**Q：上传 Excel 提示需要 SheetJS？**
A：`.xlsx` 解析依赖 CDN 上的 SheetJS，离线环境拿不到。请在 Excel 里"另存为 CSV"后再上传。

**Q：为什么一些明显的大额正常交易也被标出来了？**
A：这是**规则命中**而非异常结论。R01 大额等规则本身就是"值得看一眼"的提示。你可以：
- 在「阈值设置」里调高金额阈值
- 把该对手方加入**白名单**
- 直接人工判断它有合理解释并忽略

**Q：为什么同名的人会被标出来？**
A：系统对姓名相似（编辑距离 ≤ 1）也会提示，但会明确注明"须以身份证号比对确认是否同一人，避免同名误判"。请务必核对。

**Q：改了阈值后，之前的结果还能比吗？**
A：不能。系统会提示"口径已变更，与历史分析不可直接比较"，并把口径签名记入历史。

**Q：报告能直接签发吗？**
A：不能。它是**初稿**：结论段留空、无签署。必须由你复核、补充结论并签发。

**Q：我的数据会上传到哪？**
A：上传文件只在你的浏览器内存中解析，不上传服务器。发给大模型的只有问题与结构化摘要（笔数、金额、规则编号），不含完整流水与身份证号。

## 五、给复核人的检查清单

拿到系统输出后，建议按此顺序复核：

1. **数据质量**：借贷是否平衡？不平衡凭证与未勾对流水是否已解释？
2. **口径**：统计期间、阈值、白名单是否符合本次审计方案？
3. **信号**：高等级信号逐笔看"命中依据"，确认数据本身无误
4. **链路与四流**：断点与疑似回流是否有业务合理解释？
5. **关联方**：姓名的必须用身份证号确认；股权链条需工商档案佐证
6. **评分**：检查拉高分数的维度是否依赖低质量数据
7. **报告**：确认结论段由其本人填写、声明未被删改、证据缺口已列入待核实事项
